ClipTable

一个常驻任务栏的小工具：你复制什么，它自动收成表格，攒够了一次性粘进 Excel。

能做什么

复制即收表 — 名单、数据行、整张网页表格，按行列自动拆好
三种形态 — 表格 / 记事板 / 图片，轻点 Shift 切换
计算台 — 在表格里敲算式直接算，旁边带速记板
一键导出 — 复制为表格（直接粘进 Excel）、CSV、xlsx
模板填充 — 录一次模板，之后批量套用
全内存 — 不联网、不落盘，退出即清空
